# PDF 浏览与图片阅读增强设计

- 日期：2026-08-03
- 状态：设计已确认，待实施
- 影响范围：Android 目录浏览、PDF 阅读器、单图阅读、连续图片阅读
- 使用场景：个人使用工具，仅进行基础功能性验证

## 1. 背景与目标

应用目前能够浏览目录并打开视频、音频、静态图片和 GIF，但 `.pdf` 会落入未知媒体类型并可能错误进入音视频播放链路。现有图片阅读器虽然支持单图和连续阅读，但双指缩放未使用两指中点作为缩放锚点；连续阅读也缺少可拖动的目录图片进度条。

本次实现以下目标：

1. 识别并浏览服务器目录中的 PDF 文件；
2. PDF 采用纵向连续阅读，支持双指缩放、页码、加载和错误重试；
3. PDF 只使用阅读期间的临时缓存，退出后自动清理；
4. 单图与连续图片阅读均以两指中点作为缩放中心；
5. 连续图片阅读增加可拖动进度条，上限为文件夹内图片总数；
6. 新增独立“PDF”目录筛选项和 PDF 图标；
7. 保持刘海屏、挖孔屏和系统手势导航区域适配。

## 2. 已确认的产品行为

### 2.1 PDF 阅读模式

- 使用纵向连续滚动模式；
- 默认按屏幕宽度完整展示页面；
- 支持 `1×–5×` 双指缩放；
- 显示当前页和总页数；
- 支持加载状态、错误状态和重试；
- 不实现文本搜索、复制、链接、表单、批注和签名。

### 2.2 PDF 缓存

- PDF 在阅读前下载到应用专用临时缓存；
- 退出阅读器后自动删除本次文件；
- 配置变化不重复下载；
- 下载取消或失败后不保留半成品；
- 应用下次启动时清理异常退出遗留的过期缓存。

### 2.3 图片阅读增强

- 单图和连续阅读均修复双指中点缩放；
- 连续阅读底部增加可拖动进度条；
- 拖到第 N 张并松手后直接跳到第 N 张；
- 进度条与上下功能区同步显示和自动隐藏；
- 自动隐藏时长复用配置页已有的 `3 / 5 / 10 / 15 秒 / 不隐藏`设置。

## 3. 媒体分类与导航

### 3.1 媒体类型

新增 `MediaKind.PDF`：

- 对不区分大小写的 `.pdf` 扩展名分类为 PDF；
- PDF 不属于 `isPlayable`，不得进入音视频队列；
- 未知媒体维持原行为，本次不扩大未知格式处理范围。

### 3.2 目录界面

- 目录筛选栏新增“PDF”；
- PDF 文件行显示独立 PDF 图标；
- 点击 PDF 进入独立 `PdfReaderRoute`；
- “PDF”筛选只显示当前目录内的 PDF，不包含目录和其他媒体。

### 3.3 路由参数

`PdfReaderRoute` 保存：

- 根目录 ID；
- PDF 逻辑地址；
- 显示文件名。

路由不长期保存服务器实际地址。ViewModel 每次下载前使用当前会话端点从逻辑地址生成请求地址，从而兼容服务器地址刷新。

## 4. PDF 数据与组件边界

数据链路如下：

```text
目录列表
  -> PdfReaderRoute
  -> PdfReaderViewModel
  -> PdfDocumentRepository
  -> cacheDir/pdf 临时文件
  -> Android PdfRenderer
  -> Compose 纵向连续阅读界面
```

建议组件职责：

- `PdfReaderViewModel`：管理下载、打开、页数、当前页、页面错误及重试状态；
- `PdfDocumentRepository`：生成当前请求地址、执行临时下载、刷新失效端点并控制文件生命周期；
- `PdfDocumentHandle`：持有 `ParcelFileDescriptor` 与 `PdfRenderer`，串行打开和渲染页面；
- `PdfPageBitmapCache`：按内存预算缓存可视页及邻近页位图；
- `PdfReaderScreen`：展示加载、错误和纵向连续页面，不承担网络与文件管理。

## 5. PDF 下载与缓存生命周期

1. 进入路由后在 `cacheDir/pdf` 创建 `.part` 文件；
2. 使用当前服务器会话生成请求地址并流式写入；
3. 完整下载成功后再原子改名为临时 `.pdf`；
4. 使用可随机访问的文件描述符创建 `PdfRenderer`；
5. 退出阅读器时先关闭页面、渲染器和文件描述符，再删除临时文件；
6. 下载取消、HTTP 失败或文件写入失败时立即删除 `.part`；
7. 应用启动时删除超过过期时间的遗留 PDF 缓存；
8. 屏幕旋转等配置变化复用同一 ViewModel 和临时文件，不重新下载。

若网络请求失败且可能由端点失效导致，则调用现有会话刷新机制，并使用新地址重试一次；不进行无限重试。

## 6. PDF 页面渲染

### 6.1 渲染策略

- `PdfRenderer` 的打开和页面渲染均在后台线程完成；
- 对渲染器访问进行串行化；
- 首先渲染当前可见页面，再预取前后一页；
- 离视口较远的页面只保留尺寸信息，不持续持有位图；
- 页面位图使用有上限的 LRU 缓存，淘汰时释放资源；
- 内存压力下减少预取并降低目标渲染尺寸。

### 6.2 清晰度

- 初始页面按视口宽度渲染；
- 放大后仅当当前位图分辨率不足时，重新渲染可见页；
- 手势过程中优先复用现有位图，手势结束后再补充高清渲染，避免每个手势事件触发渲染；
- 重渲染不重新下载 PDF。

### 6.3 当前页

当前页定义为屏幕中可见面积最大的 PDF 页面。页面列表滚动或跳转后，以该页更新 `当前页 / 总页数`。

## 7. PDF 阅读界面与交互

### 7.1 加载与内容

- 加载阶段显示返回按钮、文件名和居中的“正在加载 PDF”；
- 下载完成并读取总页数后显示纵向页面列表；
- 页面之间保留窄间距；
- 顶部半透明功能区显示返回、文件名和页码；
- 单击页面切换功能区显示与隐藏；
- 本次不增加 PDF 双击动作。

### 7.2 缩放与滚动

- 双指缩放使用两指中点作为锚点；
- 缩放后中点下方原有文档内容保持在中点附近；
- `1×` 时单指纵向滑动用于翻页；
- 放大后允许横向移动，同时保留纵向连续滚动；
- 缩回 `1×` 时清除多余横向偏移；
- 平移范围按缩放后的文档宽度钳制。

### 7.3 安全区域

- 页面内容允许绘制到屏幕边缘；
- 返回按钮、文件名、页码和底部控制位于 `safeDrawing` 安全区内；
- 适配刘海屏、挖孔屏、状态栏和系统手势导航区；
- 横竖屏切换后恢复当前页，并按新宽度重新渲染，不重新下载。

## 8. 图片双指中点缩放

### 8.1 共用手势输入

单图和连续阅读统一采集：

- `calculateCentroid` 得到的双指中点；
- 缩放倍率变化；
- 双指平移距离；
- 当前视口尺寸。

缩放状态计算放在可单元测试的纯 Kotlin reducer 中，UI 只负责传递手势参数和应用结果。

### 8.2 单图模式

- X、Y 两个方向均以双指中点为缩放锚点；
- 缩放后保持锚点下方的图片内容不跳位；
- 偏移按放大后的实际显示边界钳制；
- 切换图片或恢复 `1×` 时重置偏移；
- 保留现有左右滑动切图、单击功能区和双击复位行为。

### 8.3 连续阅读模式

- 横向缩放和平移以双指中点为锚点；
- 缩放前记录中点命中的图片及其图片内局部位置；
- 列表重新布局后调整滚动量，使同一内容继续位于两指中点；
- 两指手势消费缩放和平移，普通单指纵向滑动继续交给 `LazyColumn`；
- 已显示图片不因手势事件重新发起网络加载，仅在必要时调整可见项解码质量。

## 9. 连续图片阅读进度条

### 9.1 数据规则

- 仅在 `ImageReaderMode.COMIC` 连续阅读模式显示；
- 图片序列沿用当前目录排序后的 `state.images`；
- 最小值为 `1`，最大值为 `state.images.size`；
- 静态图片与 GIF 均计入总数；
- 视频、音频、PDF、未知文件和子目录不计入；
- 当前值为屏幕中可见面积最大的图片序号。

### 9.2 拖动行为

- 拖动期间显示目标序号，但不连续加载所有经过的图片；
- 松手后调用列表直接跳转到目标索引；
- 长距离跳转不使用逐项滚动动画；
- 跳转完成后同步更新锚点、顶部张数和进度条；
- 只有一张图片时显示 `1 / 1`，进度条禁用。

### 9.3 布局与自动隐藏

底部半透明功能区从上到下排列：

```text
当前张数 / 文件夹图片总数
可拖动进度条
图片 / 动图 / 漫画模式选择
```

- 进度条与上下功能区同步显示和隐藏；
- 单击图片重新显示功能区；
- 复用配置页已有自动隐藏时长；
- 滚动、缩放、跳转或拖动进度条后重新计时；
- 正在拖动进度条时禁止自动隐藏；
- 底部控件遵循导航栏安全边距。

## 10. 状态与错误处理

PDF 阅读状态至少包含：

- `Downloading`：正在下载；
- `Opening`：正在打开并读取页数；
- `Content`：可阅读；
- `DocumentError`：整个文档无法打开；
- `PageError`：单页渲染失败。

用户可见错误：

- 网络或服务器错误：显示中文原因和“重试”；
- 缓存空间不足：停止下载并提示清理空间；
- 文件损坏或格式无效：提示“PDF 文件无效或已损坏”；
- 加密或需要密码：提示“当前版本暂不支持加密 PDF”；
- 单页渲染失败：仅该页显示错误占位和“重试”，其他页继续可读。

本项目是个人使用工具。本次只做与改动直接相关的基础验证，不增加广泛审查。

### 11.1 单元测试

- `.pdf` 分类、PDF 筛选以及不进入播放队列；
- 当前端点生成、失败后刷新一次和临时文件清理；
- PDF 当前页计算和页码边界；
- 单图与连续阅读的双指中点缩放 reducer；
- 连续阅读进度值、总数和目标索引映射；
- 自动隐藏计时在拖动期间暂停、操作后重启。

### 11.2 必要 UI 与冒烟测试

- Compose 测试验证 PDF 入口、加载、错误重试、页码和 PDF 筛选；
- Compose 测试验证连续阅读进度条显示、拖动跳转和自动隐藏；
- 手势测试验证单图和连续阅读缩放锚点不会回到屏幕中心；
- 使用一个本地多页 PDF 做模拟器冒烟，确认连续滚动、缩放、旋转和退出清理；
- 运行相关编译、现有基础测试及 ARM64 Release 构建门禁。

### 11.3 明确不执行

- 不做 PDF 模糊测试或恶意文件专项审计；
- 不为本次功能增加独立 PDF 渲染进程；
- 不执行大范围设备、厂商和 Android 版本兼容矩阵；
- 不审查无关音视频、服务器或安装包功能；
- 不升级无关依赖。

- PDF 链接交互；
