# 视频返回时后台播放修复设计

- 日期：2026-08-03
- 状态：已实现并通过基础自动验证
- 影响范围：Android 视频播放器返回导航与会话级后台播放策略

## 1. 问题

当前视频播放器虽然提供“后台播放”复选框，但从播放器按顶部返回键或系统返回键离开时，路由策略只根据媒体类型判断退出动作。只要最后确认的媒体是视频，就会无条件停止播放并清空队列，因此勾选状态不会影响返回行为。

应用切换到其他应用时的前后台生命周期策略能够读取该复选框；问题仅存在于离开视频播放器页面的导航路径。

## 2. 目标行为

### 2.1 未勾选后台播放

- 从视频播放器返回目录或首页时，保存当前进度；
- 停止视频并清空播放队列；
- 不显示仍在播放的迷你播放器；
- 保持当前默认行为。

### 2.2 已勾选后台播放

- 从视频播放器返回目录或首页时，保存当前进度；
- 不发送停止或清空命令，当前媒体与队列继续由播放服务持有；
- 视频页面销毁后分离画面 Surface，不继续在目录页面渲染视频画面；
- 声音继续播放，并允许通过目录页迷你播放器和系统媒体通知控制；
- 再次打开播放器时重新绑定视频 Surface，并以服务中的当前状态和位置显示。

### 2.3 会话和生命周期规则

- 后台播放仍是当前视频路由会话的临时开关；每次新建视频播放器路由时默认不选中；
- 普通模式与全屏模式共享同一个勾选状态；
- 切换到其他应用时沿用现有规则：勾选时继续播放，未勾选时临时暂停并在返回前台后按条件恢复；
- 音频播放器不读取视频后台播放开关，保持现有返回与后台播放行为；
- 本次不实现画中画，后台播放只保留音频、队列和系统媒体控制。

## 3. 方案

扩展播放器路由退出决策，使其同时接收：

1. 最近一次确认的媒体类型；
2. 当前视频会话是否已勾选后台播放。

退出动作规则如下：

| 媒体状态 | 后台播放 | 退出动作 |
| --- | --- | --- |
| 已确认视频 | 未勾选 | 保存进度、停止并清空、离开页面 |
| 已确认视频 | 已勾选 | 只保存进度并离开页面 |
| 已确认音频 | 不适用 | 沿用音频现有的只离开页面行为 |
| 尚未确认媒体 | 不适用 | 只离开页面，避免误清理其他会话 |

`Ready` 视频和曾确认视频但当前处于 `Connecting`、`Failed` 或 `Empty` 的播放器入口必须使用同一决策，避免重连瞬间按返回键绕过开关。

## 4. 状态与组件边界

- `VideoPlayerScreen`：只展示并更新复选框，不直接控制服务生命周期。
- `MediaViewerApp`：持有当前路由会话的勾选状态，并把它传给退出策略。
- `PlayerRouteLifecyclePolicy`：作为纯 Kotlin 决策层，根据媒体身份和勾选值返回 `LEAVE_ONLY` 或 `STOP_AND_CLEAR`。
- `PlayerViewModel.leave()`：保存播放快照后离开，不停止媒体。
- `PlayerViewModel.stopAndClear()`：保存快照后停止并清空，用于未勾选的视频退出。
- `PlaybackService`、LibVLC 与 MediaSession：继续持有勾选后保留的播放会话，本次不改变其所有权和命令协议。

## 5. 竞态与异常边界

- 路由退出开始后继续沿用现有 `leaving` 防重入，顶部返回键和系统返回键不能重复执行退出命令；
- 重连期间保留最近确认的视频身份，同时读取同一路由保存的勾选状态；
- 未确认媒体类型时不得因为请求参数看似视频而清空可能属于其他播放器的队列；
- 已勾选后返回目录，即使随后应用进入后台，也不得因视频路由已销毁而补发停止或暂停命令；服务继续按后台媒体会话运行；
- 重新进入播放器形成新路由后，开关恢复默认未选中；若用户再次返回且未重新勾选，则按未勾选规则停止并清空。

## 6. TDD 与基础验证

先修改测试并确认在当前生产代码上失败，再做最小实现：

1. 纯策略测试：已确认视频且勾选时返回 `LEAVE_ONLY`；未勾选时返回 `STOP_AND_CLEAR`；音频和未确认媒体不受影响。
2. 导航 Compose 测试：勾选后返回目录，队列和当前视频保留，迷你播放器出现；新播放器路由的复选框重新默认关闭。
3. 导航 Compose 测试：未勾选时返回目录，队列仍被清空。
4. 重连入口测试：已确认视频在临时无当前项时，勾选状态仍能决定返回是否清空。
5. 现有应用切后台策略测试保持通过，证明没有改变“切换其他应用”的行为。
6. 只执行相关 JVM、Compose/设备基础测试、编译和 Release 门禁，不增加无关全面审查。

## 7. 验收场景

1. 播放视频，不勾选后台播放，按顶部返回键：回到原目录，声音停止，队列清空。
2. 播放视频，勾选后台播放，按顶部返回键：回到原目录，声音继续，迷你播放器可控制，队列保留。
3. 对场景 1、2 分别使用系统返回键，结果相同。
4. 场景 2 中重新打开播放器：画面恢复到服务当前播放位置，后台播放复选框默认未选中。
5. 在视频页面勾选后台播放后切换到其他应用：继续播放；返回应用后状态立即同步。
6. 在视频页面未勾选后台播放后切换应用：临时暂停，回到应用后仅在切后台前正在播放时恢复。

## 8. 范围外

- 不实现画中画、悬浮窗或目录页视频画面；
- 不持久化后台播放复选框；
- 不修改播放速度、进度时钟、画面比例、自动隐藏或队列编辑行为；
- 不修改音频播放器退出策略；
- 不升级 LibVLC、Media3 或其他依赖。
